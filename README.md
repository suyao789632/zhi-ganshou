# 指・感受

以 p5.js、ml5.js HandPose 與 Tone.js 製作的雙手粒子聲音互動作品。

## 操作方式

- 進入網站後允許攝影機權限。
- 右手捏合蓄力，放開產生粒子爆炸與手碟聲音。
- 左手上下移動演奏音階，左右移動調整回音。
- 按 `F` 可切換全螢幕。

## 隱私

攝影機影像只在使用者的瀏覽器中即時分析，網站不會主動上傳或儲存影像。

## GitHub Pages

在 repository 的 **Settings → Pages** 中，將來源設定為 **Deploy from a branch**，選擇 `main` 與 `/ (root)` 後儲存。
